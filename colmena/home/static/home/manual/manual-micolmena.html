01 · Introducción

Bienvenido a Mi Colmena

Mi Colmena es una plataforma orientada al acompañamiento y la gestión de procesos relacionados con apiarios, colmenas, mantenimientos y actividades apícolas.

Este manual describe el funcionamiento del sitio web público (Home) y del proceso de acceso seguro al sistema. A través del Home, cualquier visitante puede conocer la organización, consultar los servicios apícolas, contactar al equipo y, si cuenta con una cuenta autorizada, ingresar a la plataforma.

Cada procedimiento se explica mediante capturas reales de la plataforma e instrucciones paso a paso, con marcadores, llamadas y diagramas, para que una persona que nunca haya usado el sistema pueda comprenderlo con facilidad.

Qué encontrará en este manual
  • El recorrido completo por el sitio público de Mi Colmena.
  • Servicios, contacto y elementos de navegación.
  • Ingreso al sistema con usuario y contraseña.
  • Verificación en dos pasos (2FA) y recuperación de contraseña.

03 · Requisitos

Antes de comenzar

Para visitar el sitio público y, si corresponde, ingresar al sistema, tenga en cuenta los siguientes requisitos.

①

Conexión a Internet

Una conexión estable para cargar el sitio y enviar el formulario de contacto.

②

Dispositivo compatible

Computador, portátil, tablet o celular con un navegador actualizado.

③

Navegador moderno

Google Chrome, Microsoft Edge, Mozilla Firefox o Safari, en una versión reciente.

④

Para ingresar al sistema

Un usuario previamente creado y autorizado por la organización.

🔒

Importante: Mi Colmena no tiene registro público desde el Home. Las cuentas de acceso son creadas y autorizadas por la organización; desde el sitio público no es posible crear una cuenta por cuenta propia.

17 · Seguridad del login

Mensajes y comportamientos de seguridad

Mensaje real: credenciales incorrectas

El sistema muestra: “Usuario o contraseña incorrectos. Intentos restantes: 2.”

El número de intentos lo indica la propia pantalla; el manual no asigna valores que no aparezcan en ella.

Otros comportamientos de protección
🔒

Campos vacíos

Si Usuario o Contraseña se envían sin diligenciar, el sistema no permite continuar y solicita completar los datos obligatorios.

⏳

Bloqueo temporal

Tras varios intentos fallidos, el acceso puede suspenderse temporalmente como medida de protección. Espere el tiempo indicado por el sistema antes de intentar de nuevo.

🚫

Usuario inactivo

Una cuenta desactivada no puede ingresar. Debe solicitar la activación a la organización.

👤

Usuario sin perfil

Si la cuenta no tiene un perfil asignado, no se dirige a ningún panel. La organización debe asignar el rol correspondiente.

Las tarjetas describen comportamientos de seguridad con ayudas editoriales; no representan alertas simuladas del sistema.

18 · Verificación en dos pasos

Verificación 2FA

1 2 3 4

Después de validar usuario y contraseña, algunas cuentas requieren un segundo factor. El sistema envía un código de 6 dígitos al correo registrado.

Elementos de la verificación
  • 1Código de 6 dígitos. Campo para escribir el código recibido (en la guía, ejemplo ficticio 123456).
  • 2Verificar e iniciar sesión. Botón que valida el código y continúa.
  • 3¿No recibiste el código? · Reenviar código. Opción para solicitar un nuevo envío.
  • 4Aviso de envío al correo. Indica que el código fue enviado al correo registrado, que se muestra parcialmente oculto. El código vence en 5 minutos.
✉️

El código llega al correo registrado. Por seguridad nunca lo comparta ni lo escriba en este manual.

La imagen es un recorte ampliado de la captura real para destacar la tarjeta de verificación; no se agregó ni modificó ningún elemento de la interfaz.

19 · Reenvío 2FA

Si no llega el código

1 2 3 4 5

Escena real de la verificación. El recuadro inferior muestra ampliada la zona de reenvío.

4 5
Elementos de la pantalla
  • 1Aviso de envío. Indica que el código fue enviado al correo registrado (que se muestra parcialmente oculto) y que vence en 5 minutos.
  • 2Campo del código. Espacio para los 6 dígitos; en la guía se usa solo el ejemplo ficticio 123456.
  • 3Verificar e iniciar sesión. Botón para continuar tras escribir el código.
  • 4Reenviar código. Opción “¿No recibiste el código?” para solicitar un nuevo envío al correo registrado.

Cómo proceder
  • Puede solicitar un nuevo código con Reenviar código.
  • El nuevo código llega al correo registrado.
  • Al recibirlo, escríbalo en el campo correspondiente y verifique.
  • No escriba códigos reales en el manual; use solo 123456 como ejemplo.
⏱️

Espere a que termine el temporizador para volver a usar Reenviar código y revise también la carpeta de correo no deseado.

20 · Recuperar contraseña

Recuperar la contraseña

4 1 2 3

Si olvidó su contraseña, use la opción ¿Olvidó su contraseña? del Login. En la ventana de recuperación solo debe escribir el correo asociado a su cuenta.

Elementos de la ventana
  • 1Correo electrónico. Campo para escribir el correo registrado (el marcador de posición muestra un correo de ejemplo).
  • 2Enviar instrucciones. Botón que solicita el código de recuperación.
  • 3Cerrar (X). Botón en la esquina superior del recuadro para salir de la ventana de recuperación.
  • 4Instrucción. La ventana indica que se enviará un código de 6 dígitos y un enlace seguro al correo para restablecer la contraseña.
Cómo proceder
  • Escriba su correo registrado.
  • El sistema envía un código de recuperación a ese correo (ejemplo de referencia: 123456).
  • Continúe con el proceso para crear una nueva contraseña.
  • Si no desea continuar, cierre la ventana con la X o use “Volver al inicio de sesión”.
🔐

Por seguridad, el sistema no revela públicamente si un correo existe. No escriba códigos ni contraseñas reales dentro de este manual.

Recomendaciones de seguridad

Proteja sus accesos
  • No comparta sus credenciales.
  • No comparta los códigos 2FA.
  • Utilice una contraseña segura.
  • No reutilice contraseñas de otros servicios.
Buenas prácticas
  • Cierre sesión en equipos compartidos.
  • Verifique siempre el remitente de los correos.
  • Mantenga actualizado su correo de recuperación.
  • Cambie la contraseña ante cualquier actividad sospechosa.
